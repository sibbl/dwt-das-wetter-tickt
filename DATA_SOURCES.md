# Data Sources and Rights

DWT displays raster animation data fetched at runtime from the Deutscher
Wetterdienst (DWD) WarnWetter service.

Data basis: Deutscher Wetterdienst (DWD), WarnWetter raster data reproduced
visually.

DWT is an independent app and is not affiliated with or endorsed by DWD. The
MIT License in this repository applies only to the original project code and
assets. It does not license DWD data, trademarks, or third-party material.

## Publication Status

The WarnWetter endpoints currently used by the app are not clearly identified
as DWD Open Data. Before publishing the app, obtain written permission from DWD
for this use or migrate the app to a DWD source whose license explicitly
permits redistribution and app use.
